# COVID-19 Chest X-ray Classification and Image Generation

This project compares **GAN** and **Diffusion Models** for synthetic COVID-19 X-ray image generation and trains a **ResNet18** classifier to distinguish COVID vs Non-COVID cases, supported by Grad-CAM visualization and traditional ML baselines.

## 🔧 Features
- 🧬 DCGAN and Diffusion model comparison
- 🧠 ResNet18 classifier with Grad-CAM explainability
- 🌳 RandomForest and Logistic Regression baselines
- ☁️ Streamlit web app for live prediction
- 📊 Modular, reusable, GitHub-ready codebase
